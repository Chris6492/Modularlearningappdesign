
  # Modular Learning App Design

  This is a code bundle for Modular Learning App Design. The original project is available at https://www.figma.com/design/sQoGwFonAk78VXIQk2tfEQ/Modular-Learning-App-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ##Running the Backend code
  
  pip install langchain langchain-openai python-dotenv.
  
  Create a .env file and enter your openai api key.
  
  Run cd src/app/Backend
  
  Run python3 main.py

  pip install -r requirments.txt
